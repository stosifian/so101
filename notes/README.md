# Notes

Two tracks, kept separate on purpose so the final write-up is in the user's own voice.

- `mine/YYYY-MM-DD.md`: the user's notes. Claude creates each day's file from `mine/_TEMPLATE.md` and never edits it afterwards.
- `claude/YYYY-MM-DD.md`: Claude's log. It is more exhaustive and records the numbers, run IDs, decisions and surprises the user may not have written down.
- `LESSONS_LEARNED.md`: gotchas that are worth more than a day entry.
