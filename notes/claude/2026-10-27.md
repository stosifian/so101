## Surprises
- **Wobble scales with lever arm** (user): little on pan with the arm folded (6c), noticeable on lift with the arm extended (6b). Expected from reach × flex angle and the larger inertia of an extended arm. So the dwell is pose/joint-dependent; and the 6c pan run can't judge min-jerk vs linear (different geometry). A fair test would be the same lift run twice, linear vs min-jerk.
- **End-effector wobble at every stop is invisible to the encoders** (user saw it; at 13 ramp ends in the 79° lift run the lift never reversed and idle joints moved 0–1 tick). So it's structural flex (links, mounts, clamp, table) excited by the linear ramp's instant stop. Implications: encoder-based settle can't see it, so Phase 2 needs a measured dwell; min-jerk ramps should reduce it.
